# 第五章：单字取码规则

字根记熟了，接下来就是本章的问题：**拿到一个字，到底怎么打出它的编码？**

答案取决于这个字属于哪一类。五笔把字分成四类，各有各的规则：

| 类型 | 怎么认出来 | 取码规则 |
|------|-----------|---------|
| **键名字** | 字根表**每句口诀的第一个字** | 连击该键 4 次 |
| **单笔画** | 一 丨 丿 丶 乙（只有 5 个） | 区首键 ×2 + L ×2 |
| **成字字根** | 在字根表里，但不是键名字 | 报户口 + 一笔 + 二笔 + 末笔 |
| **合体字** | 其余所有字（绝大多数） | 按拆出的字根个数决定 |

下面逐类展开。

---

## 一、键名字

**怎么认**：每句字根口诀的**第一个字**就是键名字。「王旁青头戋五一」的第一个字是「王」，所以 **G 键的键名字是「王」**。同理 F 键是「土」（土士二干十寸雨）、J 键是「日」（日早两竖与虫依）。

25 个键名字：

| 区 | 键名字 |
|----|--------|
| 横区 G F D S A | [[码:王\|gggg]] [[码:土\|ffff]] [[码:大\|dddd]] [[码:木\|ssss]] [[码:工\|aaaa]] |
| 竖区 H J K L M | [[码:目\|hhhh]] [[码:日\|jjjj]] [[码:口\|kkkk]] [[码:田\|llll]] [[码:山\|mmmm]] |
| 撇区 T R E W Q | [[码:禾\|tttt]] [[码:白\|rrrr]] [[码:月\|eeee]] [[码:人\|wwww]] [[码:金\|qqqq]] |
| 捺区 Y U I O P | [[码:言\|yyyy]] [[码:立\|uuuu]] [[码:水\|iiii]] [[码:火\|oooo]] [[码:之\|pppp]] |
| 折区 N B V C X | [[码:已\|nnnn]] [[码:子\|bbbb]] [[码:女\|vvvv]] [[码:又\|cccc]] [[码:纟\|xxxx]] |

**规则**：键名字 = **键位 × 4**。

这是最省事的一类字——不用拆，闭着眼睛按四下同一个键。

> ⚠️ X 键的键名字是「**纟**」而不是「丝」。丝是另一个字，编码 [[码:丝\|xxgf]]。

---

## 二、单笔画：一 丨 丿 丶 乙

这 5 个字既是基本笔画，也是字根。它们的取码规则**和其他成字字根不一样**，所以要单独记：

> **先按区首键两下，再按两下 L 键。**

| 笔画 | 区 | 区首键 | 编码 |
|------|----|--------|------|
| 一 | 横 | G | [[码:一\|ggll]] |
| 丨 | 竖 | H | [[码:丨\|hhll]] |
| 丿 | 撇 | T | [[码:丿\|ttll]] |
| 丶 | 捺 | Y | [[码:丶\|yyll]] |
| 乙 | 折 | N | [[码:乙\|nnll]] |

所以「一」是 **ggll**：两个 `g`（区首键按两下）+ 两个 `l`。

**为什么偏偏是 L？**
因为 L 键在五笔里兼作**补位键**——编码位数不够时用它补齐。后面讲识别码时还会见到它。

---

## 三、成字字根

**怎么认**：在字根表里能查到，但**不是**键名字的字根。比如 G 键的「五」、F 键的「士」「十」「雨」。

**记法：报户口 + 第一笔 + 第二笔 + 最后一笔**

「**报户口**」是五笔教学里的老说法，意思是先报出自己挂靠在哪个键（也就是**所在键**），然后按书写顺序报出**第一笔、第二笔、最后一笔各自属于哪个区**。

| 字 | 报户口 | 第一笔 | 第二笔 | 最后一笔 | 编码 |
|----|--------|--------|--------|----------|------|
| [[码:五\|gghg]] | G | 一 → G | 丨 → H | 一 → G | gghg |
| [[码:士\|fghg]] | F | 一 → G | 丨 → H | 一 → G | fghg |
| [[码:雨\|fghy]] | F | 一 → G | 丨 → H | 丶 → Y | fghy |
| [[码:十\|fgh]] | F | 一 → G | 丨 → H | （只有两笔，末笔即第二笔，不重复取） | fgh |
| [[码:二\|fgg]] | F | 一 → G | 一 → G | （同上） | fgg |

**笔画不足四码时，有几笔取几码**——既不补 L，也不补识别码。

> 「十」和「二」都只有两笔，编码就是 3 位；「士」有三笔，编码 4 位。规则一致，只是笔画数不同。

（单笔画那 5 个字是唯一的例外，上一节已经单独讲过。）

---

## 四、合体字

绝大多数汉字由多个字根拼合，取码规则取决于**拆出几个字根**。

### 字根数 ≥ 4：取 1、2、3、末

取**第一个 + 第二个 + 第三个 + 最后一个**字根，中间的字根全部丢掉。

| 字 | 拆法 | 取码 | 编码 |
|----|------|------|------|
| [[码:照\|jvko]] | 日 + 刀 + 口 + 灬 | 日 刀 口 灬（正好 4 个，全取） | jvko |
| [[码:繁\|txgi]] | 每 + 攵 + 幺 + 小…（多于 4 个） | 取第 1、2、3 个 + 最后一个 | txgi |
| [[码:例\|wgqj]] | 亻 + 一 + 夕 + 刂 | 取全部 4 个 | wgqj |

### 字根数 = 2 或 3：取全部 + 识别码

字根不够 4 个时，编码会「不够长」，容易重码。这时补一个**识别码**把编码凑到 4 位。

| 字根数 | 取码 | 例 |
|--------|------|----|
| 3 个 | 第 1、2、3 个字根 + 识别码 | [[码:豪\|ypeu]] = 亠 + 冖 + 豕 + 识别码 u |
| 2 个 | 第 1、2 个字根 + 识别码 | [[码:天\|gdi]] = 一 + 大 + 识别码 i |
| 2 个 | 同上 | [[码:孕\|ebf]] = 乃 + 子 + 识别码 f |

识别码怎么求，是下一章的全部内容。**它只由两件事决定：末笔是哪种笔画、字是什么结构。**

### 字根数 = 1：不存在

如果一个字本身就等于一个字根，那它要么是键名字（打 4 次），要么是成字字根（走上一节的规则）——不会落进「合体字」这一类。

---

## 取码顺序图

拿到一个字，按这个顺序判断：

```
这个字是键名字吗？（字根表每句第一个字）
  → 是 → 连击该键 4 次

这个字是单笔画吗？（一 丨 丿 丶 乙）
  → 是 → 区首键 ×2 + L ×2

这个字在字根表里吗？
  → 是 → 成字字根：报户口 + 一笔 + 二笔 + 末笔（笔画不足四码则少取）

否则 → 合体字：
        字根 ≥ 4 → 取 1、2、3、末
        字根 = 3 → 取全部 + 识别码
        字根 = 2 → 取全部 + 识别码
```

---

## 读完你应该能做什么

- 通过口诀第一个字，认出 25 个键名字
- 说出单笔画那 5 个字的特殊规则，并解释 L 是什么
- 用「报户口 + 一笔 + 二笔 + 末笔」推出一个成字字根的编码
- 数出一个合体字拆成几个字根，从而决定取码方式
- 明白「识别码」出现的条件：字根不足 4 个

下一章讲识别码——五笔中最关键、也最容易卡住的概念。

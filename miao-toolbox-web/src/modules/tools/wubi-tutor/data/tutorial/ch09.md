# 第九章：重码与 Z 键

## 重码

五笔的重码**极少**——这是它相比拼音的最大优势。

但「极少」不是「没有」。偶尔会遇到两个字编码完全相同的情况：

- 例如「去」和某字的编码可能相同
- 重码时，输入法会弹出候选列表让你选择

重码的处理方式：
1. **首选字**直接上屏（不用选）
2. **次选字**按数字键 2 选择
3. 如果候选列表只有一个字，自动上屏

实际使用中，五笔重码率低于 2%，大多数时候**不需要选字**。

## Z 键：万能学习键

Z 键不用于常规编码，它是一个**通配符**——类似搜索中的 `*`。

### 用法 1：忘了某个字根

打 [[字:照]] 时，如果忘了「灬」在哪个键，可以这样：

```
jvkoz
```

`z` 代表「我不确定这个位置是什么」。输入法会搜索所有匹配 `jvko?` 的字，给你候选列表。

### 用法 2：查编码

输入 `z` + 已知部分，可以反查一个字的编码。

### 注意

Z 键功能**取决于输入法软件**是否支持。五笔 86 编码本身不含 Z，Z 的行为由输入法引擎实现。

本工具的 v1 版本暂不支持 Z 键交互——但你可以用「查码」Tab 来查任意字的编码。

## 容错码

部分输入法软件支持**容错码**——允许一定的容错：

- 个别字的编码可以有多种合法输入
- 这是为了照顾不同拆字习惯

容错码不是五笔 86 标准的一部分，具体支持取决于输入法软件。

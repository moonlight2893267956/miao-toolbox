# 第四章：拆字五原则

## 为什么需要拆字原则

同一个字可能有多种拆法。比如「自」可以拆成「丿+目」，也可以拆成「白+一」——到底哪个对？

五笔用五条原则来消除歧义，确保每个字的拆法**唯一且规范**。

## 原则一：书写顺序

**按正确的书写顺序拆字**，不能跳步、不能倒序。

- ✅ [[字:照]] = 日 + 刀 + 口 + 灬（先写日，再写刀，再写口，最后写灬）
- ✅ [[字:新]] = 立 + 木 + 斤（先立，再木，后斤）
- ❌ 照 = 灬 + 口 + 刀 + 日（倒序，错误）

## 原则二：取大优先

在多种拆法中，**取字根最大的那种**——也就是拆出的零件尽可能大。

- ✅ [[字:百]] = 丆 + 日（两个字根）
- ❌ 百 = 一 + 白（虽然看起来也合理，但「白」比「日」大，但这里应该取「丆+日」因为取大优先要从前往后依次取最大）

更准确的例子：
- ✅ [[字:井]] = 二 + 刂（两个字根）
- ❌ 井 = 一 + 一 + 刂（三个字根，太小了）

## 原则三：兼顾直观

拆出的字根要**符合人们对汉字结构的直观认识**。

- ✅ [[字:自]] = 丿 + 目（直观上就是撇+目）
- ❌ 自 = 白 + 一（虽然笔画也对，但不直观）

## 原则四：能连不交

如果两个字根可以「相连」也可以「相交」，优先选「相连」的拆法。

**连**：字根之间接触但不穿透。比如「且」= 月 + 一（一在月下方，相连）。

**交**：字根之间穿透交叉。比如「且」如果拆成「日+丨+一」就有交。

- ✅ [[字:天]] = 一 + 大（相连）
- ❌ 天 = 二 + 人（相交）

## 原则五：能散不连

如果一个字可以拆成「散开」的字根，也可以拆成「相连」的字根，优先选「散开」。

**散**：字根之间有明确间距。比如「旦」= 日 + 一（一在日下方，可以视为散）。

- ✅ [[字:午]] = 丿 + 一 + 十（散）
- ❌ 午 = 丿 + 干（连）

## 五原则的优先级

这五条原则不是并列的，使用时按以下优先级：

1. **书写顺序**（必须满足，否则一切免谈）
2. **取大优先**（满足书写顺序后，尽量取大字根）
3. **兼顾直观**（取大优先有多种选择时，选更直观的）
4. **能连不交**（前几条仍无法决定时，选连不选交）
5. **能散不连**（最后才考虑散 vs 连的选择）

- 说出拆字五原则及其优先级
- 对一个字判断它应该怎么拆
- 理解「连」与「交」的区别

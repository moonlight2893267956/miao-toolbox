# 第六章：识别码

## 为什么需要识别码

当一个字的字根不足 4 个时（即拆出来的字根只有 2 个或 3 个），编码会「不够长」，导致大量重码。

比如「吧」和「邑」：
- 吧 = 口 + 巴 → 编码 kc（只有 2 码）
- 邑 = 口 + 巴 → 编码 kc（同样 2 码）

光看编码 `kc` 无法区分这两个字。五笔的解决方案是**补一个识别码**，把编码凑到 4 位（或至少 3 位）。

## 识别码 = 末笔 × 字型

识别码由两个因素决定：

1. **末笔笔画**：这个字的最后一笔是横、竖、撇、捺还是折
2. **字型结构**：这个字是左右结构、上下结构还是杂合结构

### 末笔笔画（5 种）

| 笔画 | 代号 |
|------|------|
| 横 | 1 |
| 竖 | 2 |
| 撇 | 3 |
| 捺 | 4 |
| 折 | 5 |

### 字型结构（3 种）

| 字型 | 代号 | 特征 | 举例 |
|------|------|------|------|
| 左右型 | 1 | 左右排列 | 你、好、明 |
| 上下型 | 2 | 上下排列 | 字、是、想 |
| 杂合型 | 3 | 非左右非上下 | 中、国、这 |

### 识别码交叉表

末笔（行）× 字型（列）→ 对应键位：

| | 左右(1) | 上下(2) | 杂合(3) |
|---|---------|---------|---------|
| **横(1)** | G | F | D |
| **竖(2)** | H | J | K |
| **撇(3)** | T | R | E |
| **捺(4)** | Y | U | I |
| **折(5)** | N | B | V |

### 一句话记住：末笔在哪个区，就去哪个区里找

不用背 15 个格子，记住这两步：

1. 看**末笔**是哪种笔画 → 决定去**哪个区**
2. 看**字型** → 决定打该区的**第几个键**

| 字型 | 打该区的第几个键 |
|------|-----------------|
| 左右结构 | 第 **1** 个键 |
| 上下结构 | 第 **2** 个键 |
| 其余结构（杂合） | 第 **3** 个键 |

拿交叉表验证：末笔是横 → 去横区（G F D）；左右打第 1 个 → G，上下打第 2 个 → F，
其余打第 3 个 → D ✓ 与表一致。

## 实战推导

### 例 1：[[字:吧]]

- 拆字：口 + 巴（2 个字根，不足 4 码，需补识别码）
- 末笔：巴的最后一笔是「乚」（竖弯钩）→ **折(5)**
- 字型：口在左、巴在右 → **左右型(1)**
- 识别码：折 × 左右 → **N**（折区第 1 个键）
- 完整编码：k + c + n = [[码:吧\|kcn]]

### 例 2：[[字:邑]]

- 拆字：口 + 巴（和「吧」拆出来**完全一样**）
- 末笔：同样是 **折(5)**
- 字型：口在上、巴在下 → **上下型(2)**
- 识别码：折 × 上下 → **B**（折区第 2 个键）
- 完整编码：k + c + b = [[码:邑\|kcb]]

**这正是识别码存在的意义**：「吧」和「邑」的字根完全一样，光看 `kc` 分不出是哪个字。
识别码只让最后一位不同——`n`（左右）与 `b`（上下）——两者就区分开了。

### 例 3：[[字:中]]

- 拆字：口 + 丨（2 个字根）
- 末笔：竖 → **竖(2)**
- 字型：独体字 → **杂合型(3)**
- 识别码：竖 × 杂合 → **K**
- 完整编码：k + h + k = [[码:中\|khk]]

> 「中」还有一级简码，实际打字按 [[码:中\|k]] + 空格就行（见第七章）。
> 但**它的全码是 khk** —— 学识别码先看全码，简码是另一层优化。

## 末笔的特殊规定

1. **包围型**：取被包围部分的末笔。如「进」的末笔取「井」的末笔（竖）
2. **「刀、九、力、七」**：以折作为末笔（这些字的末笔按规定算折）
3. **「我、成」**：以撇作为末笔

## 什么时候不需要识别码

- 字根数 ≥ 4 个（编码已够 4 码）
- 键名字（连击 4 次）
- 成字字根（按笔画取码）
- 有简码的字（可以直接打简码）

## 读完你应该能做什么

- 理解识别码存在的意义（消除重码）
- 掌握末笔笔画 × 字型结构 → 键位的推导方法
- 能判断一个字是否需要识别码

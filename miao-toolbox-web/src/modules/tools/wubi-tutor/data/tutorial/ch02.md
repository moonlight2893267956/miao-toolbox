# 第二章：键盘分区与指法

## 五区在键盘上的位置

打开你的键盘，看字母区。五笔把 25 个键按五行排列，每行就是一个区：

```
横区（1区）   Q  W  E  R  T     →  五笔不用这行（这是撇区）
              A  S  D  F  G     →  横区
              Z  X  C  V  B     →  折区
              ...
```

等等——五笔的分区和键盘的物理行不是简单对应的。正确的对应关系是：

```
第一行（上排）：Q W E R T  →  撇区（3 区）
第二行（中排）：A S D F G  →  横区（1 区）
第三行（下排）：Z X C V B  →  折区（5 区）

第一行右半：Y U I O P  →  捺区（4 区）
第二行右半：H J K L    →  竖区（2 区）
第三行右半：N M        →  竖区/折区延续
```

实际上，五笔 86 版的标准排列是：

| 区 | 键位（从左到右） | 口诀方向 |
|----|------------------|----------|
| 横区 | G F D S A | 从右到左 |
| 竖区 | H J K L M | 从左到右 |
| 撇区 | T R E W Q | 从右到左 |
| 捺区 | Y U I O P | 从左到右 |
| 折区 | N B V C X | 从右到左 |

## 每个键的「位号」

每个区有 5 个键，从左到右编号为 1\~5（但注意排列方向交替）：

- **横区** G(1) F(2) D(3) S(4) A(5)
- **竖区** H(1) J(2) K(3) L(4) M(5)
- **撇区** T(1) R(2) E(3) W(4) Q(5)
- **捺区** Y(1) U(2) I(3) O(4) P(5)
- **折区** N(1) B(2) V(3) C(4) X(5)

位号的含义：**区号 + 位号 = 该键在五笔中的坐标**。例如 G = 1区1位，K = 2区3位。

## 标准指法

十指分工，每个手指负责固定的键：

```
左手小指：A  Q  Z
左手无名指：S  W  X
左手中指：D  E  C
左手食指：F  G  R  T  V  B
右手食指：H  J  Y  U  N  M
右手中指：K  I  ,
右手无名指：L  O  .
右手小指：P  /
```

**重要**：打字时双手放在基本键位上——左手食指在 F，右手食指在 J（键盘上有凸起标记）。每次打完一个键，手指回到基本位。

## 记忆技巧

1. **先记区，再记位**：先知道某个字根在哪个区（看起笔），再想它在区内的第几个位置
2. **口诀帮大忙**：每个键都有一句助记口诀，比如 G 键「王旁青头戋五一」
3. **不要死记**：多打几次自然就记住了，本工具的练习模式会帮你高效形成肌肉记忆

## 读完你应该能做什么

- 说出 5 个区各自的键位范围
- 知道每个键的「区号 + 位号」坐标
- 掌握标准指法（十指分工、F/J 基准键）

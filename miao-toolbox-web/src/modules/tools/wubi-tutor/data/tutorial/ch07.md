# 第七章：简码体系

## 简码的意义

五笔的全码是 4 码。但很多常用字不需要打满 4 码——打 1\~3 码加空格就能输入，这就是**简码**。

简码分三级：

| 级别 | 按键数 | 含义 | 字数 |
|------|--------|------|------|
| 简码级别 | 怎么打 | 覆盖 | 本码表字数 |
|---------|--------|------|-----------|
| 一级简码 | 1 键 + 空格 | 最高频的 25 个字 | 25 |
| 二级简码 | 2 键 + 空格 | 常用字 | 605 |
| 三级简码 | 3 键 + 空格 | 大部分常用字 | 6412 |

## 一级简码（25 个）

这 25 个字是汉语中出现频率最高的一批——**每个键恰好分到 1 个**，
所以打它们只要「按键 + 空格」，是全键盘里效率最高的部分。

按区排列（和字根口诀同序，便于一起记）：

| 区 | 键 + 字 |
|----|---------|
| 横区 | G [[码:一\|g]] ・F [[码:地\|f]] ・D [[码:在\|d]] ・S [[码:要\|s]] ・A [[码:工\|a]] |
| 竖区 | H [[码:上\|h]] ・J [[码:是\|j]] ・K [[码:中\|k]] ・L [[码:国\|l]] ・M [[码:同\|m]] |
| 撇区 | T [[码:和\|t]] ・R [[码:的\|r]] ・E [[码:有\|e]] ・W [[码:人\|w]] ・Q [[码:我\|q]] |
| 捺区 | Y [[码:主\|y]] ・U [[码:产\|u]] ・I [[码:不\|i]] ・O [[码:为\|o]] ・P [[码:这\|p]] |
| 折区 | N [[码:民\|n]] ・B [[码:了\|b]] ・V [[码:发\|v]] ・C [[码:以\|c]] ・X [[码:经\|x]] |

**记忆口诀**（按区，五句连起来正好是这 25 个字）：
- 横区：一地要在工
- 竖区：上是中（国）同
- 撇区：和的有人我
- 捺区：主产不为这
- 折区：民了发以经

## 二级简码

打前两码 + 空格即可。约 600 个字，覆盖了大量常用字。

例如：
- [[码:大\|dd]] —— 全码是 [[码:大\|dddd]]，二级简码只需 dd
- [[码:到\|gc]] —— 全码 [[码:到\|gcfj]]
- [[码:你\|wq]] —— 全码 [[码:你\|wqiy]]
- [[码:好\|vb]] —— 全码 [[码:好\|vbg]]

二级简码不需要专门背，打多了自然就记住了——如果某个字你打了前两码发现候选列表有了，直接空格确认。

## 三级简码

打前三码 + 空格。约 4000 个字。

例如：
- [[字:学]] → ipb（全码 ipbf，三级简码 ipb）
- [[字:会]] → wfc

三级简码让大部分常用字都能在 3 键内完成输入。

## 简码 vs 全码

重要原则：**能简则简**。

打全码也判对（本工具在练习时全码和简码都算正确），但实际使用中，用简码更快。

## 读完你应该能做什么

- 记住 25 个一级简码
- 理解三级简码体系的结构
- 知道「能简则简」的原则
